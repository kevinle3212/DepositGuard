# DepositGuard

Trustless rental security deposit escrow built on Solana, with AI-assisted damage assessment using Google Gemini. Built for QuackHacks by team Quack Quack.

## What it does

Security deposits today sit in a landlord's bank account. When a tenant moves
out, the landlord decides what to return, and the tenant's only recourse is to
argue or sue. DepositGuard replaces that arrangement with an on-chain escrow:
the deposit is locked by a Solana smart contract that neither the landlord,
the tenant, nor the developers can override.

At move-out, both parties may upload photos of the property's condition. Gemini analyzes the images and generates an estimated, itemized damage assessment to assist in documenting potential issues. This assessment is provided solely as an informational tool and is not legally binding. The final determination regarding damages, deductions, and security deposit returns remains the responsibility of the landlord and must comply with all applicable laws, lease agreements, and regulations.
Any estimates generated by the platform should not be considered a legal decision, professional inspection, or substitute for the landlord's independent evaluation. The platform serves as a facilitation and documentation tool, and any disputes or disagreements should be resolved through direct communication between the parties or through appropriate legal channels if necessary.

## How it works

- On-chain escrow program written in Rust with the Anchor framework, deployed
    to Solana devnet, holds the deposit in USDC.
- Web frontend built with Next.js and TypeScript, with a Phantom wallet
    connection for both parties.
- Photo upload, user accounts, and storage handled by Firebase.
- Damage comparison and itemized assessment generated by Google Gemini.

## Project status

Built in 24 hours at QuackHacks. The implementation is a working prototype on
Solana devnet using test USDC. A production deployment would require real
mainnet USDC integration and the associated compliance work, which is named
as future scope, not solved in this build.

## Limits

DepositGuard is a mediation and evidence tool, not a legal authority. Gemini
produces a proposed estimate, not a verdict. Genuine factual disputes
escalate to humans. The contract can only protect deposits actually placed
into the escrow, which works when both parties agree to it at lease signing.
